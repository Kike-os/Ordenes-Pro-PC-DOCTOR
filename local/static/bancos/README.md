Las imágenes se descargaron el 02/11/2026 como PNG rasterizados por Wikimedia (sin SVG ejecutable), se recortaron y se redujeron a
un máximo de 240 × 64 px, sin cambiar el diseño ni los colores. Las marcas pertenecen a sus titulares y aquí solo identifican el
banco de cada cuenta. Un banco sin archivo se muestra con sus iniciales. Para cambiar un logotipo, reemplaza el archivo con el
mismo nombre.
