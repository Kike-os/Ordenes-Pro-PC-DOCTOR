# Logotipos de marcas para la recepción

La ficha del equipo en **Nueva orden → Equipo** muestra aquí el logotipo de la marca cuando existe el archivo.
Si falta, se muestra un icono genérico; la marca y el modelo se guardan igual, porque no dependen del logo.

## Archivos incluidos

Los SVG de esta carpeta provienen de Simple Icons 13.21.0 (https://simpleicons.org, archivos con licencia CC0): son la marca
en un solo color, sin modificar. Las marcas registradas pertenecen a sus titulares y aquí solo identifican el equipo recibido.
Cada uno se muestra en el color corporativo que Simple Icons registra para la marca (atributo `fill`); el trazo no se modificó.
Apple, ASUS, Honor, Razer y Sony quedan en negro. Para usar el logotipo corporativo completo de un fabricante, descárgalo de su
portal de marca y guárdalo aquí con el mismo nombre.

El 13/10/2026 se añadieron del mismo catálogo: Framework, Fujifilm, Google, NEC, Sharp, System76 y Zebra.
Ese mismo día se añadió también Bitdefender (antivirus del catálogo de productos). ESET y Microsoft (Windows, Office, Microsoft 365) no están en Simple Icons: sus productos muestran un icono técnico hasta que administración suba el logotipo oficial en Configuración → Catálogo.

Sin archivo todavía (muestran el icono genérico): Brother, Canon, Compaq, Dynabook, Gigabyte, IBM, Konica Minolta, Lexmark, Microsoft, OKI, Ricoh, VAIO, Xerox y el resto de marcas. Simple Icons no las incluye; su logotipo debe bajarse del portal de marca de cada fabricante.

## Cómo añadir un logotipo

1. Descargar el archivo **oficial** desde el portal de marca o de prensa del fabricante y revisar sus condiciones de uso.
2. No modificarlo: sin recolorear, recortar ni redibujar.
3. Guardarlo en esta carpeta como `marca.svg` o `marca.png`, en minúsculas, sin tildes y con guiones en lugar de espacios.

| Marca en el sistema | Archivo |
|---|---|
| Dell | `dell.svg` |
| HP | `hp.svg` |
| Lenovo | `lenovo.svg` |
| ASUS | `asus.svg` |
| Acer | `acer.svg` |
| Apple | `apple.svg` |
| Epson | `epson.svg` |
| Konica Minolta | `konica-minolta.svg` |

Si existen los dos formatos, se usa el SVG. Tamaño recomendado para PNG: 280 px de ancho con fondo transparente.
El logotipo se muestra sobre un recuadro claro de 70 × 70 px para que se lea sin alterarlo.
